# Conference Talk & Poster Blueprints

## 1. 5-Minute Spotlight Deck (6 Slides)
1. **Title + Hook (0:30)**: Visual teaser contrasting failure of prior SOTA vs. your result.
2. **The Bottleneck (0:45)**: One crisp visual showing *why* existing approaches break.
3. **Key Insight & Method Overview (1:30)**: Clean architecture diagram + 1 core equation/mechanism.
4. **Headline Quantitative Result (1:00)**: Simplified 3–4 row table or bar chart with your delta bolded.
5. **Key Ablation / Insight (0:45)**: The single ablation or qualitative example proving *why* it works.
6. **Takeaway + QR Code (0:30)**: 3-bullet summary + Poster # + arXiv/Code QR code.

## 2. 15-Minute Oral Deck (12–14 Slides + Backup)
- Slides 1–2: Title + Real-world Motivation & Concrete Bottleneck
- Slide 3: Core Insight (1 memorable sentence + intuitive visual)
- Slides 4–6: Method Walkthrough (Overview -> Module 1 -> Module 2; highlight symbols on diagram)
- Slide 7: Experimental Setup (Datasets, Metrics, Fair Baselines in visual icons)
- Slides 8–9: Main Benchmark Comparison + Hardest OOD/Unseen Split
- Slide 10: Ablations & Efficiency Trade-off (Pareto frontier plot)
- Slide 11: Qualitative Wins **and** Honest Failure Mode
- Slide 12: Summary, Limitations & QR Code
- Slides 13–17 *(Backup)*: Full hyperparameter tables, theoretical proof sketch, extra dataset slices, runtime breakdown.

## 3. Poster 3-Column Visual Blueprint
- **Top Header**: Short Title (72pt+) | Authors & Logos | Scannable QR Code (Code + Paper)
- **Column 1 (Why?)**: Teaser visual + 3 bullet problem statement + Core Hypothesis box
- **Column 2 (How?)**: Large clean architecture diagram + 1–2 key equations with callout arrows
- **Column 3 (Does It Work?)**: Main chart/mini-table + key ablation bar plot + 2-bullet Takeaway & Limitations
